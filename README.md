# RLG G1 Face

This is the repository for the RLG G1 Face project,
an extension for the [Unitree G1](https://www.unitree.com/g1) for HRI applications.

This repository contains the documentation and the CAD files
neccessary for building and using the RLG G1 Face.

View the full documentation [here](https://robot-learning-group.github.io/rlg-g1-face/).
The documentation is made with [mdbook](https://rust-lang.github.io/mdBook/) and is deployed
on the main branch. To view pre-release documentation, you will need to build it yourself.
